# Vexil runtime for Go

The Go wire runtime for code generated by [`vexilc`](../../crates/vexilc/README.md).
It provides LSB-first bit I/O, bounded decoding, and the interfaces implemented
by generated Go types. It has no third-party dependencies and requires Go 1.22
or newer.

## Install

```sh
go get github.com/vexil-lang/vexil/packages/runtime-go@v0.1.1
```

## Core API

```go
import vexil "github.com/vexil-lang/vexil/packages/runtime-go"

writer := vexil.NewBitWriter()
writer.WriteBits(5, 4)
writer.WriteU16(1000)
writer.WriteLeb128(42)
bytes := writer.Finish()

reader := vexil.NewBitReader(bytes)
bits, err := reader.ReadBits(4)
if err != nil {
	return err
}
value, err := reader.ReadU16()
if err != nil {
	return err
}
```

Generated structs implement `Packer` and `Unpacker`:

```go
type Packer interface {
	Pack(*BitWriter) error
}

type Unpacker interface {
	Unpack(*BitReader) error
}
```

The default reader limits cap recursion at 64 levels, byte arrays and strings
at 16 MiB, and collections at 1,048,576 elements. Set application-specific
limits before decoding untrusted input.

Vexil's [compliance vectors](../../compliance/vectors/README.md) provide the
shared byte-level contract.
